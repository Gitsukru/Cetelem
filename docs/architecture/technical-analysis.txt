8. LOCALSTORAGE FRAGILE
   Problème: Pas de gestion de quota
   localStorage.setItem('counters', JSON.stringify(counters))

   Risque réel:
   - Safari iOS: quota 5-10MB
   - User avec 2 ans de données → CRASH
   - Erreur silencieuse, données perdues

   Fix nécessaire:
   try {
     localStorage.setItem(...)
   } catch (e) {
     if (e.name === 'QuotaExceededError') {
       // Proposer export + cleanup
     }
   }

9. RACE CONDITIONS
   Exemple dans script.js:949

   groupManager.updateMyScore(stats) // ← PAS d'await!

   Problème:
   - Si l'update échoue → silencieux
   - Si l'update est lente → données obsolètes affichées
   - Impossible de savoir si le save a réussi

   Fix: await groupManager.updateMyScore(stats)

10. COMPATIBILITÉ NAVIGATEUR
    Code utilise:
    - async/await (ES2017)
    - class (ES2015)
    - Optional chaining ?. (ES2020)
    - Promise.allSettled (ES2020)

    Problème: AUCUN transpilation
    Impact:
    - iOS < 14: Ne fonctionne pas
    - Android < 9: Ne fonctionne pas
    - IE 11: Mort instantanée

    Fix: Vite + @vitejs/plugin-legacy

🔴 CRITIQUE - FAIRE MAINTENANT (Cette semaine)
───────────────────────────────────────────────────────────────────────────────

1. RÉGÉNÉRER LA CLÉ SUPABASE
   ⏱ 15 minutes

   a) Aller sur Supabase dashboard
   b) Project Settings → API → Regenerate anon key
   c) Créer .env:
      VITE_SUPABASE_URL=https://xxx.supabase.co
      VITE_SUPABASE_ANON_KEY=nouvelle_clé
   d) Ajouter .env au .gitignore
   e) Modifier backend.config.js:
      key: import.meta.env.VITE_SUPABASE_ANON_KEY
   f) Révoquer l'ancienne clé

2. ACTIVER ROW LEVEL SECURITY (RLS)
   ⏱ 30 minutes

   Dans Supabase SQL Editor:

   -- Groupes: Un user ne peut modifier que ses propres scores
   ALTER TABLE groups ENABLE ROW LEVEL SECURITY;

   CREATE POLICY "Users can view groups they're in"
     ON groups FOR SELECT
     USING (participant_id = auth.uid() OR is_host = true);

   CREATE POLICY "Only hosts can delete groups"
     ON groups FOR DELETE
     USING (is_host = true AND creator_id = auth.uid());

3. INSTALLER JEST ET LANCER LES TESTS
   ⏱ 5 minutes

   npm install --save-dev jest
   npm test

   Vérifier que tests/utils.test.js passe ✓
