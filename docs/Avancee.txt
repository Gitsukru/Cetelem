  👥 3. AUTHENTIFICATION & GESTION UTILISATEURS

  Système d'Authentification

  Constat : Application ANONYME (par design)

  L'application fonctionne sans authentification utilisateur :
  - Pas de login/mot de passe
  - Pas de Supabase Auth
  - Identification par nom simple lors de la jointure groupe

  Flux Utilisateur :

  1. Mode Local (Sans Groupe) :
    - Stockage 100% localStorage
    - Aucune donnée serveur
    - Privé et hors ligne
  2. Mode Groupe (Collaboratif) :
    - Création groupe → Génération code 6 chars (ex: ABC123)
    - Jointure groupe → Nom participant + Code groupe
    - Identification par participant_id (UUID Supabase)
    - Pas de session persistante (reconnexion via historique local)

  Code Clé (GroupManager.js:29-60) :
  async createGroup(groupName, creatorName) {
    const result = await this.provider.createGroup(groupName, creatorName);
    this.currentGroup = {
      id: result.groupId,
      code: result.code,
      name: result.name
    };
    this.currentParticipant = {
      id: result.participantId,
      name: creatorName
    };
    this.saveGroup(); // localStorage
  }

  Points Forts :
  - ✅ Simplicité extrême (pas de friction utilisateur)
  - ✅ Anonymat total pour utilisateurs non-groupe
  - ✅ Validation stricte des noms (Validators.validateParticipantName)
  - ✅ Rate limiting sur création/jointure groupes

  Limitations de Sécurité :
  - ⚠️ Aucune protection contre usurpation d'identité groupe
  - ⚠️ N'importe qui avec le code peut rejoindre
  - ⚠️ Pas de propriétaire vérifiable (créateur = premier participant)
  - ⚠️ Scores modifiables côté client (trust client)

  Recommandations :

  1. Court terme (Garder anonyme) :
    - Ajouter signature JWT côté serveur pour valider scores
    - Implémenter webhook Supabase pour vérification
  2. Moyen terme (Ajout auth optionnelle) :

    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),

  ALTER TABLE participants ADD COLUMN user_id UUID REFERENCES users(id);
  3. Long terme (Auth complète) :

    let dayCount = 0, weekCount = 0, monthCount = 0, yearCount = 0, totalCount = 0;

      if (date >= monthStart) monthCount += count;
