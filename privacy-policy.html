Politique de Confidentialité

Dernière mise à jour : 8 novembre 2025

1. Introduction

Zikirmatik (« l'Application ») respecte votre vie privée. Cette politique de confidentialité explique quelles données nous collectons, comment nous les utilisons, et vos droits.

2. Données collectées

2.1 Données locales (stockées sur votre appareil)

  • Compteurs de zikir : nombre de répétitions, catégories personnalisées
  • Historique : dates et statistiques de vos sessions
  • Préférences : paramètres de l'application (thème, langue, sons)
  • Livres : suivi de lecture, notes personnelles

Ces données restent sur votre appareil et ne sont jamais envoyées automatiquement vers nos serveurs.

2.2 Données de groupe (si vous rejoignez un groupe)

  • Nom de participant : le nom que vous choisissez (pseudonyme accepté)
  • Statistiques de groupe : compteurs partagés avec votre groupe
  • Code de groupe : pour identifier votre groupe

Ces données sont stockées sur Supabase (hébergement Europe) et visibles par les membres du groupe.

2.3 Données de sauvegarde (optionnel)

  • Code de sauvegarde : code unique généré aléatoirement
  • Données exportées : compteurs et paramètres (si vous créez une sauvegarde)

Sauvegardes automatiquement supprimées après 90 jours.

2.4 Analytics anonymes (optionnel)

  • Événements d'usage : actions dans l'app (création groupe, utilisation tesbihat)
  • Données techniques : type d'appareil, navigateur, langue
  • ID anonyme : identifiant aléatoire (non lié à votre identité)

Aucune donnée personnelle identifiable. Ces analytics nous aident à améliorer l'app.

3. Comment nous utilisons vos données

  • Fonctionnement de l'app : sauvegarder vos compteurs, synchroniser les groupes
  • Amélioration : comprendre l'usage pour ajouter des fonctionnalités
  • Support technique : diagnostiquer et corriger les bugs

Nous ne vendons JAMAIS vos données.

Nous ne partageons JAMAIS vos données avec des tiers (sauf services techniques : Supabase, Sentry).

4. Services tiers utilisés

  • Supabase (base de données) : hébergement Europe, certifié RGPD
    Politique Supabase
  • Sentry (monitoring erreurs) : anonyme, données techniques uniquement
    Politique Sentry
  • Netlify (hébergement) : infrastructure Europe/USA
    Politique Netlify

5. Vos droits (RGPD)

Vous avez le droit de :

  • Accéder à vos données (export JSON disponible dans l'app)
  • Rectifier vos données (modifiable dans l'app)
  • Supprimer vos données :
    • Données locales : Paramètres → Réinitialiser
    • Données de groupe : contacter contact@zikirmatik.app
  • Portabilité : export JSON téléchargeable
  • Opposition : ne pas créer de compte/groupe

6. Sécurité

  • HTTPS activé (toutes les communications chiffrées)
  • Pas de mot de passe (pas de risque de fuite)
  • Codes de groupe aléatoires (6 caractères)
  • Rate limiting (protection anti-spam)

7. Cookies et stockage local

L'application utilise :

  • localStorage : stockage des compteurs et paramètres (essentiel au fonctionnement)
  • Service Worker : mode hors ligne (PWA)

Aucun cookie tiers de tracking publicitaire.

8. Durée de conservation

  • Données locales : jusqu'à suppression par vous
  • Groupes inactifs : supprimés après 365 jours d'inactivité
  • Sauvegardes : 90 jours
  • Analytics : 90 jours

9. Mineurs

L'application est accessible à tous. Pour les mineurs de moins de 16 ans, le consentement parental est requis pour créer un groupe ou une sauvegarde cloud.

10. Modifications

Cette politique peut être mise à jour. La date de dernière modification est indiquée en haut. Les changements importants seront notifiés dans l'application.
